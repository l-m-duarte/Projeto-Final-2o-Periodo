# Projeto Final


PROJETO REDIGIDO POR LUIZ MIGUEL DUARTE DE SOUZA FREITAS E ANTHONY ALMEIDA GARRONE

FEITO COM C# E MYSQL

Esse projeto não se trata mais do que a aplicação do Windows Forms ensinado através das 3 publicações do Google Sala de Aula, somente com o tema trocado para refletir o de um dos roteiros em aula, sobre eletrodomésticos.
Nosso único incremento relativo ao tema do roteiro foi adicionar uma tabela "dono" para manter pelo menos uma relação 1:N
